Implement Task 8: Job Description Parser

This commit implements a deterministic, provider-independent Job Description
parser as outlined in Task 8.

Changes include:
- `src/lib/schemas/jdParser.ts`: Zod schemas for input validation and structured
  parsed output representation.
- `src/lib/services/jdParser.ts`: Layered parsing logic using heuristics to
  extract job details (title, company, work arrangement, etc) and section-based
  bullet extraction for responsibilities, qualifications, and skills.
- `src/app/api/jd/parse/route.ts`: A protected API endpoint that uses the parser
  and maintains current authentication conventions (401 mock).
- `src/app/jd-parser/page.tsx`: A straightforward UI for pasting a job
  description, validating input length (30,000 max chars), and reviewing the
  structured results with warnings.
- `src/lib/api/client.ts`: Added `parseJd` to the centralized fetch wrapper.
- Focused unit and UI tests for parser heuristics, API behavior, and UI states.
